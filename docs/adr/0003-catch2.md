# 3. Catch2

## Context

The client requires tested code and test-driven development. We need a C++ testing framework that makes tests easy to write and read, and that integrates with CTest.

Alternatives considered:
- **Google Test**: widely used, but requires a separate installation and more boilerplate.
- **doctest**: similar to Catch2, slightly lighter, but less documentation and community.
- **Catch2**: header-friendly, downloaded automatically by CMake's FetchContent, and tests read like plain English.

## Decision

We use Catch2 v3. It is downloaded and built automatically on the first configure, via CMake's `FetchContent`. Each `TEST_CASE` is registered with CTest individually.

## Status

Proposed

## Consequences

- Tests are short and read like a specification.
- The first build downloads Catch2 from GitHub and needs internet access. `make clean` removes the download, so the next build needs it again.
- Catch2 adds to the build time.
